# 《福爾摩沙地形探險隊》
- 年級 / 科目 / 單元:國小五年級 / 社會 / 台灣的地形
- 學習目標:分辨五種地形,說出台灣主要山脈與地形區位置。
- 故事與玩法:探險隊地圖被撕碎,天黑前逐關拼回,找到營地。
- 關卡安排:
  1. 地形名牌:名牌放上剖面圖
  2. 山脈排隊:由東到西排列
  3. 台地探照:選出所有台地
  4. 居民轉盤:轉到居民住的地形
  5. 營地路線:輸入四位數
- 道具(拿到→用到):指南針1→2、地圖2→3、望遠鏡3→4、路線詩4→5。

## 題目與答案
**第1關 地形名牌**
- 線索:五張剖面圖說明:A 很高、坡很陡,山峰連綿;B 不太高,小山頭起伏和緩;C 頂上平平的,四周是陡坡,像桌子;D 又低又平,在海邊或河流下游;E 四周被山圍住,中間低平。名牌:山地、丘陵、台地、平原、盆地。
- 答案:A 山地、B 丘陵、C 台地、D 平原、E 盆地。
- 解說:台地和平原都平,差在台地比較高、四周有陡坡;盆地是「四周高、中間低」。

**第2關 山脈排隊**
- 線索:指南針指出東西方向。牆上寫:「沿著北回歸線,從太平洋邊往西走,會依序翻過四條山脈。」五張卡:中央山脈、玉山山脈、阿里山山脈、海岸山脈、雪山山脈。
- 答案:海岸山脈 → 中央山脈 → 玉山山脈 → 阿里山山脈(雪山山脈用不到)。
- 解說:海岸山脈緊鄰東岸,和中央山脈之間是花東縱谷;玉山山脈、阿里山山脈在中央山脈西側。雪山山脈在北部,北回歸線沒有經過。

**第3關 台地探照**
- 線索:地圖上標了七個地點:林口台地、台北盆地、桃園台地、大肚台地、屏東平原、八卦台地、埔里盆地,但名字的最後兩字被撕掉,只看得到地名(林口、台北、桃園、大肚、屏東、八卦、埔里)和地形顏色。紙條:「選出所有台地。」
- 答案:林口、桃園、大肚、八卦。
- 解說:台北、埔里是盆地;屏東是平原。台地多分布在西部平原和山地之間。

**第4關 居民轉盤**
- 線索:望遠鏡看到三位居民的對話框:
  甲:「我住在北部,四周都是山,夏天特別悶熱。」
  乙:「我家在西南部,這裡是台灣最大的平原,種了很多稻米。」
  丙:「我家在東北部,平原呈三角形,面向太平洋。」
  每人下方一個轉盤,選項:台北盆地、台中盆地、嘉南平原、屏東平原、蘭陽平原、林口台地。
- 答案:甲 台北盆地、乙 嘉南平原、丙 蘭陽平原。
- 解說:台中盆地在中部,屏東平原在最南端但不是最大;蘭陽平原在宜蘭,呈三角形。

**第5關 營地路線**
- 線索:地圖上的編號:1 玉山山脈、2 中央山脈、3 嘉南平原、4 台北盆地、5 林口台地、6 海岸山脈。路線詩:「先登上台灣最高峰所在的山脈,向西走到最大的平原,再北上到四周環山的北部盆地,最後爬上盆地西邊的台地。」紙條:「依序輸入經過地點的編號。」
- 答案:1345。
- 解說:台灣最高峰玉山在玉山山脈,不在中央山脈(常見錯誤:輸入 2345)。林口台地在台北盆地的西邊。
