# 《極地研究站的密碼》
- 年級 / 科目 / 單元:國中七年級 / 數學 / 正負數的四則運算
- 學習目標:熟練正負數加減乘除、正負號規則與運算順序。
- 故事與玩法:研究站斷電,氧氣用完前要解開五道門抵達發電室。
- 關卡安排:
  1. 冰上數線:移動企鵝棋子
  2. 冷凍庫:輸入溫差
  3. 警報燈:選出所有負數
  4. 符號轉盤:轉出兩個符號
  5. 電力排序:算式卡由小排到大
- 道具(拿到→用到):溫度計1→2、鑰匙2→3、符號轉盤3→4、放大鏡4→5。

## 題目與答案
**第1關 冰上數線**
- 線索:冰面上畫著 -10 到 +10 的數線,企鵝站在 0。指令卡:「(+5)+(-8)+(+2)」,正數往右、負數往左。
- 答案:把企鵝放到 -1。
- 解說:0 → 5 → -3 → -1。常見錯誤:忽略負號算成 15。

**第2關 冷凍庫**
- 線索:用溫度計量到冷凍庫是 -18°C,走廊是 25°C。門上寫:「密碼是走廊比冷凍庫高幾度。」
- 答案:43。
- 解說:25 - (-18) = 25 + 18 = 43。常見錯誤:25 - 18 = 7。

**第3關 警報燈**
- 線索:控制箱裡六個按鈕:A (-2)×(-3);B (-4)×5;C (-1)×(-1)×(-1);D (-6)÷(-2);E 8÷(-4);F (-3)×0。紙條:「按下所有結果是負數的。」
- 答案:B、C、E。
- 解說:A=6、B=-20、C=-1、D=3、E=-2、F=0。負號個數是奇數,乘積才是負的;0 不是正數也不是負數。

**第4關 符號轉盤**
- 線索:門上:「(-6) ○ (-2) ○ 3 = -12」,兩個圓圈各是一個轉盤,可轉到 +、-、×、÷。
- 答案:第一個 +,第二個 ×。
- 解說:(-6)+(-2)×3 = -6 + (-6) = -12,要先乘除後加減。16 種組合中只有這一種等於 -12。常見錯誤:由左往右算,(-6)+(-2)=-8,再 ×3 = -24。

**第5關 電力排序**
- 線索:五張卡(第五張的小字要用放大鏡看):a (-3)+(-5);b (-2)×(-3)-10;c 12÷(-4);d (-1)-(-7);e (-18)÷(-6)×(-2)。紙條:「由小到大插進電池槽。」
- 答案:a → e → b → c → d。
- 解說:a=-8、e=3×(-2)=-6、b=6-10=-4、c=-3、d=6。e 要由左往右算;若先算 (-6)×(-2)=12,會誤得 -1.5。
