# 《失色的文字王國》
- 年級 / 科目 / 單元:國中七年級 / 國文 / 修辭法
- 學習目標:辨認譬喻四類、轉化、誇飾、摹寫、層遞,並說出依據。
- 故事與玩法:王國的句子失去色彩,燭火燒完前修好五座圖書館。
- 關卡安排:
  1. 修辭信箱:句子投進信箱
  2. 譬喻轉盤:轉到譬喻類型
  3. 轉化之窗:選出所有轉化句
  4. 層遞階梯:排列句子磚
  5. 王國日記:輸入四位數
- 道具(拿到→用到):墨水瓶1→2、放大鏡2→3、書籤3→4、鑰匙4→5。

## 題目與答案
**第1關 修辭信箱**
- 線索:四個信箱:譬喻、擬人、誇飾、摹寫。四張紙條:①她的笑容像春天的陽光。②小草從泥土裡探出頭來,好奇地看著世界。③我餓得可以吞下一頭牛。④天邊的晚霞一片橘紅,又漸漸轉成深紫。
- 答案:①譬喻 ②擬人 ③誇飾 ④摹寫。
- 解說:④描寫眼睛看到的顏色變化,是視覺摹寫。

**第2關 譬喻轉盤**
- 線索:用墨水補上字後,四個句子各配一個轉盤(明喻/暗喻/略喻/借喻):A 老師的話像一盞明燈。B 時間是一條長河。C 人生,一場旅行。D 夜空中撒滿了閃亮的珍珠。
- 答案:A 明喻、B 暗喻、C 略喻、D 借喻。
- 解說:明喻用「像、如」;暗喻用「是、成為」;略喻省略喻詞;借喻連喻體(星星)都省略,只留喻依(珍珠)。

**第3關 轉化之窗**
- 線索:六扇窗上的句子:a 月亮害羞地躲進雲裡。b 他像一頭牛一樣有力氣。c 把憂愁折成紙船,放進河裡流走。d 他的嗓門大得整棟樓都聽得見。e 教室裡的桌椅排得整整齊齊。f 花兒在微風中點頭微笑。紙條:「打開所有用了轉化的窗。」
- 答案:a、c、f。
- 解說:a、f 把物當人寫(擬人);c 把抽象的憂愁寫成可以折的東西(形象化)。b 有「像」是譬喻;d 是誇飾;e 只有疊字。

**第4關 層遞階梯**
- 線索:第一階已寫好「我們要愛護自己的家」,另有三塊磚:「愛護整個地球」「愛護自己的國家」「愛護自己的社區」。紙條:「排成層遞,一階比一階大。」
- 答案:家 → 社區 → 國家 → 地球。
- 解說:層遞是把事物依大小、輕重、深淺一層層排列,讓語意逐步加強。

**第5關 王國日記**
- 線索:日記五句:①湖面平靜得像一面鏡子。②山路陡得幾乎要碰到天。③風吹過松林,沙沙作響。④太陽伸了個懶腰,爬上山頭。⑤我們走了一個小時,終於到達山頂。鎖上寫:「依序輸入擬人、譬喻、誇飾、摹寫句的編號。」
- 答案:4123。
- 解說:④擬人、①譬喻、②誇飾、③聽覺摹寫;⑤只是平鋪直敘,沒有用到這四種修辭,是干擾句。
