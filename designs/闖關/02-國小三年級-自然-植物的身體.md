# 《魔法溫室救援隊》
- 年級 / 科目 / 單元:國小三年級 / 自然 / 植物的身體
- 學習目標:認識植物各部位與功能,分辨葉脈和蔬菜吃的部位。
- 故事與玩法:精靈睡著了,解開五座溫室機關,天黑前喚醒它。
- 關卡安排:
  1. 植物名牌:貼名牌到各部位
  2. 長大的順序:排生長卡
  3. 挖菜園:選出所有吃根的菜
  4. 葉子轉盤:轉到對的葉脈
  5. 精靈晚餐:輸入四位密碼
- 道具(拿到→用到):種子1→2、小鏟子2→3、放大鏡3→4、菜單4→5。

## 題目與答案
**第1關 植物名牌**
- 線索:一株開花的植物圖,有四個空白框:土裡分岔的部分、從土面往上直直撐著的部分、綠色扁平的部分、頂端彩色的部分。名牌:根、莖、葉、花。
- 答案:土裡→根;直直撐著→莖;綠色扁平→葉;頂端彩色→花。
- 解說:根在土裡,莖把植物撐起來,葉長在莖上,花通常開在莖的頂端或旁邊。

**第2關 長大的順序**
- 線索:把種子放進花盆後,出現四張卡:開花、結出果實(裡面有種子)、發芽長出根、長出莖和葉。
- 答案:發芽長出根 → 長出莖和葉 → 開花 → 結出果實。
- 解說:種子先發芽,長大後開花,花謝了結果實,果實裡又有新的種子。

**第3關 挖菜園**
- 線索:用小鏟子挖出六種菜,每種都看得到吃的部分長在哪裡:紅蘿蔔、白蘿蔔、牛蒡、馬鈴薯、蓮藕、高麗菜。紙條:「選出所有我們吃的是『根』的菜。」
- 答案:紅蘿蔔、白蘿蔔、牛蒡。
- 解說:馬鈴薯和蓮藕長在土裡或泥裡,但它們是「莖」(上面有芽眼、有節);高麗菜吃的是葉。長在土裡不一定是根。

**第4關 葉子轉盤**
- 線索:三片葉子由左到右排列:榕樹葉、稻子的葉、扶桑葉。用放大鏡才看得清楚葉脈:榕樹葉和扶桑葉的葉脈像網子一樣分岔,稻葉的葉脈是一條條直線並排。每片葉子下面有一個轉盤,可以轉到「網狀脈」或「平行脈」。
- 答案:左 網狀脈、中 平行脈、右 網狀脈。
- 解說:葉脈分岔像網子叫網狀脈;一條條平行排列叫平行脈。葉脈是葉子運送水分和養分的通道。

**第5關 精靈晚餐**
- 線索:菜單寫著上菜順序「甘蔗汁、炒菠菜、烤地瓜、炒花椰菜」。牆上的編號表:「1 從土裡吸水、抓住土壤;2 撐起植物、運送水分;3 製造養分;4 吸引昆蟲幫忙,之後會結果實」。紙條:「密碼是每道菜吃的部位的編號,照上菜順序。」
- 答案:2314。
- 解說:甘蔗吃莖(2)、菠菜吃葉(3)、地瓜吃根(1)、花椰菜吃的是還沒開的花(4)。常見錯誤:把地瓜當成莖、或不知道花椰菜是花。
