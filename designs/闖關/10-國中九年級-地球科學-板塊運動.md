# 《深海鑽探船求生記》
- 年級 / 科目 / 單元:國中九年級 / 地球科學 / 板塊運動
- 學習目標:分辨三種板塊交界,算海底年齡,解釋台灣地質現象。
- 故事與玩法:鑽探船當機,地震前修好五個控制台駛回台灣。
- 關卡安排:
  1. 交界分類:地形卡放上交界圖
  2. 海底年齡:輸入年代
  3. 隱沒方向:轉兩個隱沒轉盤
  4. 海洋誕生:圖卡依序排好
  5. 台灣檔案:選出所有對的敘述
- 道具(拿到→用到):尺1→2、指北針2→3、膠卷3→4、地震儀4→5。

## 題目與答案
**第1關 交界分類**
- 線索:三張交界示意圖:兩板塊箭頭「← →」互相遠離、「→ ←」互相靠近、一上一下「⇅」水平錯開。五張卡:中洋脊、東非大裂谷、海溝、喜馬拉雅山、聖安地列斯斷層。
- 答案:張裂(← →):中洋脊、東非大裂谷;聚合(→ ←):海溝、喜馬拉雅山;錯動(⇅):聖安地列斯斷層。
- 解說:喜馬拉雅山是印度板塊與歐亞板塊兩塊大陸碰撞擠壓而成,屬於聚合。

**第2關 海底年齡**
- 線索:海底地圖比例尺「1 cm = 20 km」,用尺量出鑽探點到中洋脊 3 cm。紙條:「這一側的海底每年遠離中洋脊 2 公分。鑽探點的海底大約形成於幾萬年前?(輸入數字,單位:萬年)」
- 答案:300。
- 解說:距離 3×20 = 60 km = 6,000,000 cm;6,000,000 ÷ 2 = 3,000,000 年 = 300 萬年。常見錯誤:沒換單位算成 60÷2=30。

**第3關 隱沒方向**
- 線索:台灣附近海圖(用指北針定方位):台灣東北方有琉球海溝,海溝西北側是琉球群島(島弧),位在歐亞板塊上;台灣南方有馬尼拉海溝,海溝東側是呂宋島弧(包括蘭嶼、綠島),位在菲律賓海板塊上。牆上寫:「島弧形成在上方那塊板塊。」兩個轉盤(北部、南部),選項:「菲律賓海板塊隱沒到歐亞板塊下方」「歐亞板塊隱沒到菲律賓海板塊下方」。
- 答案:北部:菲律賓海板塊隱沒到歐亞板塊下方;南部:歐亞板塊隱沒到菲律賓海板塊下方。
- 解說:隱沒的板塊下沉熔融,火山島弧出現在上方板塊。台灣北、南兩側的隱沒方向剛好相反。

**第4關 海洋誕生**
- 線索:膠卷播放四張圖卡:大西洋(寬闊海洋,中央有中洋脊)、紅海(狹長的海)、大陸地殼拱起出現裂縫、東非大裂谷(陸地上的大裂谷)。紙條:「依張裂發展的先後排好。」
- 答案:大陸地殼拱起出現裂縫 → 東非大裂谷 → 紅海 → 大西洋。
- 解說:張裂從陸地開裂開始,形成裂谷,海水灌入成狹長海洋,持續張裂後成為大洋。

**第5關 台灣檔案**
- 線索:地震儀顯示台灣一年有上萬次地震。六條敘述:A 台灣地震頻繁;B 中央山脈至今仍在緩慢上升;C 海岸山脈有許多岩石是古代海底火山噴發形成的;D 花東縱谷是歐亞板塊與菲律賓海板塊的交界帶;E 台灣海峽底下有中洋脊不斷產生新地殼;F 台灣西部平原是兩塊板塊水平錯開滑動形成的。紙條:「選出所有正確且和板塊聚合有關的敘述。」
- 答案:A、B、C、D。
- 解說:台灣位在兩板塊聚合處,擠壓造成地震和造山;海岸山脈原是呂宋島弧的一部分,碰撞後併入台灣。E、F 都是錯的:台灣海峽沒有中洋脊,西部平原主要是河流堆積形成的。
