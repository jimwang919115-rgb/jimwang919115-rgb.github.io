# 《老車站的時光檔案室》
- 年級 / 科目 / 單元:國中八年級 / 歷史 / 台灣的日治時期
- 學習目標:掌握日治起訖、三期政策、抗日方式與經濟轉變。
- 故事與玩法:老車站史料亂了,末班車開走前要整理好。
- 關卡安排:
  1. 統治年數:輸入年數
  2. 政策檔案櫃:政策卡放進抽屜
  3. 演講會海報:選出非武力抗爭
  4. 經濟帳簿:轉兩個口號轉盤
  5. 時間軸:事件排上時間軸
- 道具(拿到→用到):鑰匙1→2、煤油燈2→3、帳簿3→4、年代印章4→5。

## 題目與答案
**第1關 統治年數**
- 線索:兩張舊海報:「1895 年 清朝與日本簽訂馬關條約,割讓台灣」「1945 年 第二次世界大戰結束,日本投降」。門上寫:「日本統治台灣大約幾年?」
- 答案:50。
- 解說:1945 - 1895 = 50 年。

**第2關 政策檔案櫃**
- 線索:三個抽屜:「初期(武官總督)」「中期(同化政策)」「後期(皇民化運動)」。六張卡:實施保甲制度、進行土地與戶口調查、開始改派文官擔任總督、推行日台共學、推行國語(日語)家庭、徵召台灣人當志願兵。
- 答案:初期:保甲制度、土地與戶口調查;中期:文官總督、日台共學;後期:國語家庭、志願兵。
- 解說:初期重在鎮壓與調查;1919 年起改派文官、推行同化;1937 年中日戰爭爆發後推動皇民化,要台灣人成為效忠天皇的「皇民」。

**第3關 演講會海報**
- 線索:煤油燈照亮六張海報:台灣議會設置請願運動、台灣文化協會巡迴演講、成立台灣民眾黨、西來庵事件、霧社事件、乙未戰爭。紙條:「選出所有以非武力方式爭取權利的。」
- 答案:台灣議會設置請願運動、台灣文化協會巡迴演講、成立台灣民眾黨。
- 解說:1915 年西來庵事件後,大規模武裝抗日漸少,知識分子改以請願、辦報、演講、組黨等方式爭取權益;霧社事件是 1930 年原住民的武裝抗日。

**第4關 經濟帳簿**
- 線索:帳簿兩頁:「1920 年代:大量米、糖運往日本」「1940 年:台灣新建金屬、化學工廠,支援日本向南洋擴張」。兩個轉盤 A(前期)、B(1930 年代後期起),選項:工業日本、農業台灣/工業台灣、農業南洋/農業日本、工業台灣/商業台灣、工業日本。
- 答案:A 工業日本、農業台灣;B 工業台灣、農業南洋。
- 解說:前期台灣是日本的米糖供應地;戰爭時期為了南進,開始在台灣發展軍需工業。

**第5關 時間軸**
- 線索:年代印章蓋出時間軸刻度:1908、1915、1921、1930、1937。五張事件卡:霧社事件、台灣文化協會成立、縱貫鐵路全線通車、皇民化運動展開、西來庵事件。
- 答案:1908 縱貫鐵路全線通車、1915 西來庵事件、1921 台灣文化協會成立、1930 霧社事件、1937 皇民化運動展開。
- 解說:可從前幾關推理:建設在前期;西來庵是武裝抗日轉向非武力的分界;文協屬非武力抗爭;皇民化在中日戰爭爆發後。
