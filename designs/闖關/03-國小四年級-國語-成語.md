# 《成語書院的封印》
- 年級 / 科目 / 單元:國小四年級 / 國語 / 成語
- 學習目標:能補全常見成語、理解意思,並在句子中正確使用。
- 故事與玩法:書院的書被封印,鐘聲響完前要解開五道成語機關。
- 關卡安排:
  1. 數字門:輸入三位數
  2. 動物雕像:雕像放上底座
  3. 改錯簿:選出所有用對的句子
  4. 成語接龍:排出接龍
  5. 故事轉盤:轉出三個成語
- 道具(拿到→用到):鑰匙1→2、毛筆2→3、書籤3→4、墨水4→5。

## 題目與答案
**第1關 數字門**
- 線索:門上有三個缺字的成語和意思:「( )心二意:不專心」「( )上八下:心裡很不安」「( )牛一毛:很多裡面的一點點」。紙條:「密碼是三個缺的數字,由上到下。」
- 答案:379。
- 解說:三心二意、七上八下、九牛一毛。

**第2關 動物雕像**
- 線索:四個雕像:牛、蛇、兔、青蛙。四個底座寫著:「做多餘的事,反而壞事」「對不懂的人講道理,白費力氣」「不努力,只想靠運氣」「見識很少,眼光狹小」。
- 答案:多餘→蛇(畫蛇添足);白費力氣→牛(對牛彈琴);靠運氣→兔(守株待兔);見識少→青蛙(井底之蛙)。
- 解說:很多成語來自寓言故事,記住故事就記得意思。

**第3關 改錯簿**
- 線索:六個句子,用毛筆圈出成語用對的:
  A 弟弟考前才臨時抱佛腳,熬夜讀書。
  B 他畫的小鳥栩栩如生,好像要飛起來。
  C 這家餐廳的菜難吃得令人嘆為觀止。
  D 小明做事虎頭蛇尾,開始很認真,後來就放棄了。
  E 媽媽煮的湯差強人意,我喝了三碗還想再喝。
  F 他們兩個感情很好,真是水火不容。
- 答案:A、B、D。
- 解說:「嘆為觀止」是稱讚好到極點,不能說難吃;「差強人意」是「大致還算滿意」,不是「非常好」,和喝三碗還想喝不合;「水火不容」是彼此合不來。

**第4關 成語接龍**
- 線索:書籤夾著的那頁寫著「一心一意」,旁邊有四張卡:大公無私、發揚光大、意氣風發、光明正大。紙條:「接龍:前一個成語的最後一個字,是下一個的第一個字。用上三張卡,有一張用不到。」
- 答案:一心一意 → 意氣風發 → 發揚光大 → 大公無私。
- 解說:「光明正大」開頭的「光」沒有成語以它結尾,所以用不上。

**第5關 故事轉盤**
- 線索:塗上墨水後浮現故事,有三個空格,各有一個轉盤:
  ①「小明早上睡過頭,( )地衝出門。」選項:手忙腳亂、從容不迫、悠然自得、一帆風順
  ②「他和同學( ),終於完成了海報。」選項:同心協力、各自為政、水火不容、半途而廢
  ③「實驗失敗了好多次,他仍然( ),最後成功了。」選項:鍥而不捨、半途而廢、虎頭蛇尾、三心二意
- 答案:①手忙腳亂 ②同心協力 ③鍥而不捨。
- 解說:選成語要看句子的情境:睡過頭很著急、一起完成作品、失敗了還繼續努力。
