# 《福爾摩沙氣象巡禮》
- 年級 / 科目 / 單元:國中七年級/地理/台灣的氣候
- 學習目標:用季風、北迴歸線、地勢、雨型解釋各地氣候差異。
- 故事:從北到南、平地到高山,找回觀測精靈。
- 地圖區域:
  - 北海岸港口:東北季風冬雨;起點
  - 北迴歸線平原:氣候分區、雨型;港口隧道
  - 南部平原:冬季乾燥;吊橋
  - 高山步道:地勢與氣溫;登山口
- 鑰匙與門:該區精靈全加入得「氣象徽章」,開下一扇門。
- 過關條件:6位精靈都加入。

## 角色與題目

**給線索的 NPC**
- 氣象研究員(北海岸港口):「冬天吹東北季風,基隆、宜蘭在迎風面,冬天常下雨;中南部在背風面,冬天比較乾。五六月的梅雨是鋒面雨,夏天午後雷陣雨是對流雨。」
- 標誌塔守塔人(北迴歸線平原):「北迴歸線經過嘉義和花蓮,以北是副熱帶季風氣候,以南是熱帶季風氣候。」
- 山屋嚮導(高山步道):「高度每上升 100 公尺,氣溫大約下降 0.6°C。」

**答對才能邀請加入的角色**

1. 雨傘蛙(北海岸港口)
   - 題目:一月時,下列哪個城市最可能連續好幾天下雨?
   - 選項:A 基隆 B 高雄 C 台南
   - 答案:A
   - 解說:基隆位在東北季風的迎風面,冬季多雨。

2. 迴歸鷺(北迴歸線平原)
   - 題目:台北和高雄分別屬於哪一種氣候?
   - 選項:A 副熱帶季風/熱帶季風 B 都是熱帶季風 C 熱帶季風/副熱帶季風
   - 答案:A
   - 解說:台北在北迴歸線以北,高雄在以南。

3. 雷公雞(北迴歸線平原)
   - 題目:夏天下午常突然下大雷雨,傍晚就停,這屬於哪一種雨?
   - 選項:A 對流雨 B 鋒面雨 C 地形雨
   - 答案:A
   - 解說:白天地面受熱、空氣上升形成對流雨,所以多在午後。

4. 梅雨蝸牛(北迴歸線平原)
   - 題目:五、六月常連續陰雨好幾天,這主要是哪一種雨?
   - 選項:A 鋒面雨 B 颱風雨 C 對流雨
   - 答案:A
   - 解說:梅雨是冷暖空氣交會的滯留鋒面造成的。

5. 乾乾蜥(南部平原)
   - 題目:屏東的冬天為什麼比較乾燥?
   - 選項:A 位在東北季風的背風面 B 冬天吹西南季風 C 離海太遠
   - 答案:A
   - 解說:東北季風被中央山脈擋住,南部在背風面少雨;西南季風是夏季的風。

6. 雲霧豹(高山步道)
   - 題目:海邊(約 0 公尺)氣溫 28°C,同一時間 3000 公尺的山上大約幾度?
   - 選項:A 約 10°C B 約 25°C C 約 18°C
   - 答案:A
   - 解說:3000 ÷ 100 × 0.6 = 18,28 − 18 = 10;18 是下降的度數,不是山上氣溫。
