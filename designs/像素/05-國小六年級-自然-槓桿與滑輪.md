# 《省力村的工具祭》
- 年級 / 科目 / 單元:國小六年級/自然/槓桿與滑輪
- 學習目標:判斷槓桿是否省力,分辨定滑輪與動滑輪。
- 故事:幫工具精靈找回本領,讓工具祭開幕。
- 地圖區域:
  - 蹺蹺板公園:省力原理;起點
  - 採石場:撬棒支點;公園木門
  - 工具街:省力費力工具;採石場鐵門
  - 升旗廣場:定滑輪與動滑輪;工具街拱門
- 鑰匙與門:該區精靈全加入得「齒輪鑰匙」,開下一扇門。
- 過關條件:6位工具精靈都加入。

## 角色與題目

**給線索的 NPC**
- 蹺蹺板爺爺(公園):「施力點離支點越遠,抗力點離支點越近,就越省力。」
- 工具店阿姨(工具街):「開瓶器的抗力點在中間,很省力;鑷子的施力點在中間,比較費力,但方便夾小東西。」
- 旗桿叔叔(升旗廣場):「旗桿頂的定滑輪不省力,但把往下拉變成往上升;動滑輪跟著東西一起動,用的力大約只要一半。」

**答對才能邀請加入的角色**

1. 蹺蹺鼠(蹺蹺板公園)
   - 題目:小老鼠想用蹺蹺板把大象抬起來,小老鼠應該坐在哪裡?
   - 選項:A 離支點越遠越好 B 離支點越近越好 C 坐哪裡都一樣
   - 答案:A
   - 解說:施力臂越長越省力。

2. 撬石獾(採石場)
   - 題目:用長木棍撬起大石頭,墊在下面的支點放在哪裡最省力?
   - 選項:A 靠近石頭 B 靠近手 C 正中間
   - 答案:A
   - 解說:支點靠近石頭,抗力臂短、施力臂長,最省力。

3. 開瓶鳥(工具街)
   - 題目:開瓶器開瓶蓋時,哪一個點在中間?
   - 選項:A 支點 B 抗力點 C 施力點
   - 答案:B
   - 解說:支點在瓶蓋頂端,瓶蓋邊緣是抗力點在中間,手在最外面,所以省力。

4. 鑷子蟹(工具街)
   - 題目:鑷子屬於哪一種槓桿?
   - 選項:A 省力 B 費力,但方便操作 C 不省力也不費力
   - 答案:B
   - 解說:施力點在中間,施力臂比抗力臂短,所以費力,但可以精細夾東西。

5. 旗旗松鼠(升旗廣場)
   - 題目:升旗時往下拉繩子,旗子往上升,旗桿頂用的是什麼?
   - 選項:A 定滑輪 B 動滑輪 C 輪軸
   - 答案:A
   - 解說:定滑輪固定不動,不省力,但能改變施力方向。

6. 吊桶猴(升旗廣場)
   - 題目:用一個動滑輪提起 20 公斤重的水桶(不算滑輪重量和摩擦),大約要用多少力?
   - 選項:A 20 公斤重 B 10 公斤重 C 40 公斤重
   - 答案:B
   - 解說:動滑輪由兩段繩子一起拉住重物,大約省一半力。
