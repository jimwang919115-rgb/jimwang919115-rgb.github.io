# 《飯糰的體內大旅行》
- 年級 / 科目 / 單元:國中七年級/生物/消化系統
- 學習目標:說出消化道順序及各器官、消化液的功能。
- 故事:你變成一粒米,從嘴巴出發旅行到終點。
- 地圖區域:
  - 口腔廣場:唾液與澱粉;起點
  - 胃酸湖:胃液與蛋白質;食道下方
  - 小腸迷宮:膽汁、胰液、吸收;幽門
  - 大腸隧道:吸收水分;迷宮出口
- 鑰匙與門:該區精靈全加入得「酵素卡」,開下一段門。
- 過關條件:6位精靈都加入,抵達終點。

## 角色與題目

**給線索的 NPC**
- 唾液守衛(口腔廣場):「飯在嘴裡嚼久了會變甜,因為唾液裡的酵素把澱粉分解成麥芽糖。」
- 胃酸湖管理員(胃酸湖):「胃液有鹽酸和蛋白酶,蛋白質在這裡開始被分解。」
- 小腸導遊(小腸迷宮):「肝臟做的膽汁沒有酵素,只把油脂打散成小油滴;胰液裡有分解澱粉、蛋白質、脂質的酵素。食物不會經過肝臟和胰臟。大腸主要吸收水分。」

**答對才能邀請加入的角色**

1. 澱粉麻糬(口腔廣場)
   - 題目:饅頭嚼很久會變甜,原因是?
   - 選項:A 唾液把澱粉分解成麥芽糖 B 牙齒把糖磨出來 C 胃液流到嘴裡
   - 答案:A
   - 解說:唾液澱粉酶在口腔就開始分解澱粉。

2. 蛋白蝦(胃酸湖)
   - 題目:吃下的蛋白質,最先在哪裡開始被分解?
   - 選項:A 口腔 B 胃 C 大腸
   - 答案:B
   - 解說:唾液只分解澱粉,胃液中的蛋白酶才開始分解蛋白質。

3. 路線蟲(胃酸湖)
   - 題目:食物通過的順序,哪一條正確?
   - 選項:A 口腔→食道→胃→小腸→大腸 B 口腔→胃→食道→小腸→大腸 C 口腔→食道→胃→肝臟→小腸
   - 答案:A
   - 解說:肝臟是消化腺,分泌膽汁流入小腸,食物本身不經過肝臟。

4. 油滴鳥(小腸迷宮)
   - 題目:膽汁對脂肪有什麼作用?
   - 選項:A 用酵素把脂肪分解成脂肪酸 B 把脂肪乳化成小油滴 C 直接吸收脂肪
   - 答案:B
   - 解說:膽汁不含酵素,只讓脂肪變成小油滴,方便酵素作用。

5. 胰島狐(小腸迷宮)
   - 題目:如果胰臟無法分泌胰液,哪些養分的消化會受影響?
   - 選項:A 只有澱粉 B 澱粉、蛋白質、脂質都會 C 都不受影響
   - 答案:B
   - 解說:胰液含分解三種養分的酵素,是功能最完整的消化液。

6. 水滴蝸(大腸隧道)
   - 題目:某人拉肚子,糞便很稀,最可能是哪個器官吸收水分不夠?
   - 選項:A 大腸 B 胃 C 食道
   - 答案:A
   - 解說:大腸主要吸收水分,吸收不足糞便就會很稀。
