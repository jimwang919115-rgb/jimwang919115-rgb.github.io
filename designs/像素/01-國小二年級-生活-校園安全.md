# 《安全小隊大冒險》
- 年級 / 科目 / 單元:國小二年級/生活/校園安全
- 學習目標:分辨校園危險行為,說出安全做法。
- 故事:小精靈忘了安全規則,邀他們加入安全小隊。
- 地圖區域:
  - 走廊教室區:走路與樓梯;起點
  - 遊戲場:鞦韆、溜滑梯;走廊盡頭門
  - 水池花園:水邊安全;遊戲場旁小橋
  - 校門口:過馬路、陌生人;花園後柵欄門
- 鑰匙與門:精靈全加入得「安全徽章」,開下一區門。
- 過關條件:6位小精靈都加入。

## 角色與題目

**給線索的 NPC**
- 校工伯伯(走廊):「走廊要慢慢走、靠右邊,下雨地板很滑喔。」
- 護理師阿姨(遊戲場旁):「玩鞦韆要在旁邊排隊,溜滑梯要坐著、腳先下去。水邊危險,東西掉了請大人幫忙。」
- 導護老師(校門口):「綠燈閃了就停下來等。不認識的人要帶你走,不要跟,馬上告訴老師。」

**答對才能邀請加入的角色**

1. 跑跑兔(走廊教室區)
   - 題目:小明下課急著去廁所,在走廊上怎麼做最好?
   - 選項:A 用跑的 B 快步走、靠右邊 C 在地上滑過去
   - 答案:B
   - 解說:走廊人多,用跑的容易撞到人或滑倒。

2. 盪盪猴(遊戲場)
   - 題目:鞦韆有人在盪,你也想玩,應該站在哪裡等?
   - 選項:A 鞦韆正前方 B 旁邊排隊,等它停下來 C 鞦韆後面幫忙推
   - 答案:B
   - 解說:站在前面或後面,會被盪過來的鞦韆撞到。

3. 溜溜蛇(遊戲場)
   - 題目:溜滑梯怎麼溜最安全?
   - 選項:A 頭朝下趴著溜 B 坐著、腳朝前溜下去 C 從滑道往上爬
   - 答案:B
   - 解說:腳先下去才停得住,不會撞到頭。

4. 水滴鴨(水池花園)
   - 題目:你的球滾進水池裡了,怎麼做?
   - 選項:A 自己伸手去撈 B 請大人幫忙 C 跳下去撿
   - 答案:B
   - 解說:水池邊很滑,小朋友自己去撈可能會掉下去。

5. 紅綠燈貓(校門口)
   - 題目:你還沒走上斑馬線,綠燈就開始閃了,怎麼辦?
   - 選項:A 趕快衝過去 B 停在路邊等下一次綠燈 C 邊走邊看手機
   - 答案:B
   - 解說:綠燈閃表示快變紅燈了,停下來等最安全。

6. 小星狐(校門口)
   - 題目:不認識的叔叔說「你媽媽叫我來接你」,你怎麼做?
   - 選項:A 跟他走 B 不跟他走,馬上告訴老師 C 告訴他家裡地址
   - 答案:B
   - 解說:不認識的人說什麼都不要跟他走,先找老師確認。
