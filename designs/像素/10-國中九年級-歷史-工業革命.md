# 《蒸汽之城的煙囪》
- 年級 / 科目 / 單元:國中九年級/歷史/工業革命
- 學習目標:說明工業革命始於英國的原因、關鍵技術及影響。
- 故事:穿越到工業革命的英國,找回機器精靈。
- 地圖區域:
  - 煤礦山丘:英國的條件;起點
  - 河邊紡織廠:紡織機械、蒸汽機;山丘木門
  - 鐵路車站:交通革命;紡織廠鐵門
  - 工人街區:都市與勞工;車站出口
- 鑰匙與門:該區精靈全加入得「調查筆記」,開下一扇門。
- 過關條件:6位精靈都加入。

## 角色與題目

**給線索的 NPC**
- 老礦工(煤礦山丘):「英國煤和鐵很多,又有殖民地供應棉花、購買布料;圈地以後很多農民進城當工人,所以工業革命先從英國開始。」
- 紡織廠工頭(河邊紡織廠):「紡紗機讓紡織業最早改用機器。以前工廠要蓋在河邊靠水車轉動;瓦特改良了早就有的蒸汽機,工廠就不必靠河了。」
- 街頭記者(工人街區):「城市人口暴增,工人住得擁擠骯髒,連小孩都進工廠工作;火車把煤和貨物運到各地。電力要等到 19 世紀後期的第二次工業革命才普及。」

**答對才能邀請加入的角色**

1. 煤炭獾(煤礦山丘)
   - 題目:下列哪一項「不是」工業革命先在英國發生的原因?
   - 選項:A 煤鐵資源豐富 B 有殖民地提供原料和市場 C 工廠已大量使用電力
   - 答案:C
   - 解說:電力是 19 世紀後期第二次工業革命的事。

2. 紡錘精靈(河邊紡織廠)
   - 題目:工業革命最早大量改用機器生產的是哪個產業?
   - 選項:A 紡織業 B 汽車業 C 電子業
   - 答案:A
   - 解說:棉布需求大,紡紗、織布機最先出現;汽車、電子都晚得多。

3. 蒸汽鴞(河邊紡織廠)
   - 題目:瓦特在工業革命中的貢獻是?
   - 選項:A 第一個發明蒸汽機 B 改良蒸汽機,讓它效率更高、能廣泛使用 C 發明電燈
   - 答案:B
   - 解說:蒸汽機在瓦特之前就有,他是改良者,不是發明者。

4. 水車河狸(河邊紡織廠)
   - 題目:瓦特改良蒸汽機後,工廠為什麼可以從河邊搬到城市和煤礦附近?
   - 選項:A 不必再靠水力當動力 B 河水乾掉了 C 政府禁止在河邊蓋工廠
   - 答案:A
   - 解說:蒸汽機燒煤就能產生動力,工廠不再受河流位置限制。

5. 火車鴿(鐵路車站)
   - 題目:蒸汽火車出現後,最直接的影響是?
   - 選項:A 人和貨物運得更快、更遠 B 不再需要煤 C 城市人口減少
   - 答案:A
   - 解說:蒸汽火車本身要燒煤,它讓運輸更快,也帶動城市成長。

6. 煙囪貓(工人街區)
   - 題目:下列何者最符合工業革命初期工業城市的情況?
   - 選項:A 人口減少、街道空蕩 B 工人住處擁擠、空氣污染、有童工 C 小孩都在學校,不必工作
   - 答案:B
   - 解說:大量人口湧入城市,居住、衛生與勞工問題隨之出現。
