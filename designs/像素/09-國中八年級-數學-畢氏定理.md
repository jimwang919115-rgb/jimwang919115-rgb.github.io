# 《直角古城探險》
- 年級 / 科目 / 單元:國中八年級/數學/畢氏定理
- 學習目標:用畢氏定理求邊長、判斷直角,解決距離與測量問題。
- 故事:找回古城迷路的三角精靈。
- 地圖區域:
  - 石匠廣場:求斜邊與股;起點
  - 木匠工坊:判斷直角三角形;廣場北門
  - 城牆下:梯子與對角線;工坊石門
  - 測量塔:坐標距離;城牆鐵門
- 鑰匙與門:該區精靈全加入得「直角尺鑰匙」,開下一扇門。
- 過關條件:6位精靈都加入。

## 角色與題目

**給線索的 NPC**
- 石匠(石匠廣場):「直角三角形中,兩股的平方和等於斜邊的平方:a² + b² = c²。」
- 木匠(木匠工坊):「反過來,三邊滿足 a² + b² = c²,就是直角三角形。古人用打結成 3、4、5 段的繩子量直角。」
- 測量員(測量塔):「坐標上兩點的距離,把橫的差和直的差當作兩股,就能求出來。」

**答對才能邀請加入的角色**

1. 三角鴿(石匠廣場)
   - 題目:直角三角形兩股長 6 和 8,斜邊長是多少?
   - 選項:A 10 B 14 C 100
   - 答案:A
   - 解說:6² + 8² = 36 + 64 = 100,√100 = 10;14 是直接相加,100 是忘了開根號。

2. 斜坡羊(石匠廣場)
   - 題目:直角三角形斜邊 13、一股 5,另一股長是多少?
   - 選項:A 12 B 8 C √194
   - 答案:A
   - 解說:13² − 5² = 169 − 25 = 144,√144 = 12;√194 是把斜邊當成股去相加。

3. 繩結狐(木匠工坊)
   - 題目:下列哪一組三邊長能構成直角三角形?
   - 選項:A 4, 5, 6 B 8, 15, 17 C 2, 3, 4
   - 答案:B
   - 解說:8² + 15² = 64 + 225 = 289 = 17²;4² + 5² = 41 ≠ 36,2² + 3² = 13 ≠ 16。

4. 梯子熊(城牆下)
   - 題目:10 公尺長的梯子靠在垂直的牆上,梯腳離牆 6 公尺,梯頂離地多高?
   - 選項:A 8 公尺 B 4 公尺 C √136 公尺
   - 答案:A
   - 解說:梯子是斜邊,10² − 6² = 64,√64 = 8。

5. 對角線龍(城牆下)
   - 題目:正方形城磚邊長 5 公分,對角線長是多少?
   - 選項:A 5√2 公分 B 10 公分 C 25 公分
   - 答案:A
   - 解說:5² + 5² = 50,√50 = 5√2(約 7.07);10 是兩邊直接相加。

6. 坐標貓(測量塔)
   - 題目:坐標平面上 A(1, 2)、B(4, 6),兩點距離是多少?
   - 選項:A 5 B 7 C 25
   - 答案:A
   - 解說:橫差 3、直差 4,√(9 + 16) = 5;7 是把 3 和 4 直接相加。
