# 《月光小鎮的夜晚》
- 年級 / 科目 / 單元:國小四年級/自然/月亮的變化
- 學習目標:說出月相與農曆日期的關係,知道月亮東升西落。
- 故事:找回走散的月亮精靈,讓月相恢復。
- 地圖區域:
  - 小鎮廣場:月亮為何會亮;起點
  - 月曆花園:月相與農曆;廣場拱門
  - 東山坡:月亮的移動;花園木門
  - 觀星台:月相順序;山坡頂石門
- 鑰匙與門:該區精靈全加入得「月光碎片」,開下一扇門。
- 過關條件:6位精靈都加入。

## 角色與題目

**給線索的 NPC**
- 觀星爺爺(廣場):「月亮自己不會發光,它是反射太陽的光。」
- 月曆奶奶(月曆花園):「農曆初一幾乎看不到月亮,叫新月;初七、八是右邊亮的上弦月;十五左右是滿月;二十二、三是左邊亮的下弦月。大約一個月轉一圈。」
- 守夜貓頭鷹(東山坡):「月亮和太陽一樣,從東邊升起,慢慢爬高,再往西邊落下。」

**答對才能邀請加入的角色**

1. 光光蛾(小鎮廣場)
   - 題目:晚上的月亮看起來亮亮的,是因為?
   - 選項:A 月亮自己會發光 B 反射太陽光 C 反射地球上的燈光
   - 答案:B
   - 解說:月亮像一面鏡子,本身不發光,是太陽照到它。

2. 新月兔(月曆花園)
   - 題目:農曆初一晚上抬頭看,最可能看到什麼?
   - 選項:A 滿月 B 幾乎看不到月亮 C 上弦月
   - 答案:B
   - 解說:初一是新月,亮的那面背對我們,幾乎看不到。

3. 半月鹿(月曆花園)
   - 題目:今天看到右半邊亮的半個月亮,大約是農曆幾號?
   - 選項:A 初七、八 B 十五 C 二十二、三
   - 答案:A
   - 解說:右邊亮是上弦月,在初七、八;左邊亮的下弦月才是二十二、三。

4. 方向狐(東山坡)
   - 題目:傍晚看到月亮在東邊的山頭,過了幾個小時,它會怎麼移動?
   - 選項:A 慢慢升高,再往西邊移動 B 往東邊落下 C 一直停在東邊不動
   - 答案:A
   - 解說:月亮東升西落,跟太陽一樣。

5. 圓圓貍(觀星台)
   - 題目:今晚是農曆十五的滿月,大約要再過多久才會再看到滿月?
   - 選項:A 約 7 天 B 約 15 天 C 約 30 天
   - 答案:C
   - 解說:月相大約一個月循環一次;15 天後是新月,不是滿月。

6. 排序蛙(觀星台)
   - 題目:滿月之後,月亮亮的部分會怎麼變?
   - 選項:A 越來越大 B 越來越小,中間會經過下弦月 C 隔天馬上變新月
   - 答案:B
   - 解說:滿月後亮面慢慢變小,經過下弦月,再到新月。
