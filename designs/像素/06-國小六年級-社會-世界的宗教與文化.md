# 《地球村文化節》
- 年級 / 科目 / 單元:國小六年級/社會/世界的宗教與文化
- 學習目標:認識各宗教的經典、節日、飲食,並懂得尊重。
- 故事:走訪各街區,邀不同信仰的朋友參加文化節。
- 地圖區域:
  - 鐘樓街區:基督教;起點
  - 圓頂街區:伊斯蘭教;鐘樓東拱門
  - 蓮花河岸:佛教與印度教;圓頂南石橋
  - 中央廣場:綜合判斷;河岸大門
- 鑰匙與門:該區朋友全加入得「護照印章」,開下一扇門。
- 過關條件:6位朋友都加入。

## 角色與題目

**給線索的 NPC**
- 鐘聲姐姐(鐘樓街區):「基督教的經典是聖經,12 月 25 日的耶誕節紀念耶穌誕生。」
- 旅行家阿姨(圓頂街區):「伊斯蘭教的經典是古蘭經,信徒不吃豬肉;齋戒月白天不吃不喝,太陽下山後才進食。」
- 博物館爺爺(蓮花河岸):「佛教起源於印度,由釋迦牟尼創立;印度教把牛當作神聖的動物,許多信徒不吃牛肉。認識別人的習慣,才知道怎麼尊重朋友。」

**答對才能邀請加入的角色**

1. 鐘聲羊(鐘樓街區)
   - 題目:12 月 25 日街上掛滿燈飾和聖誕樹,這是哪一個宗教的重要節日?
   - 選項:A 基督教 B 佛教 C 伊斯蘭教
   - 答案:A
   - 解說:耶誕節紀念耶穌誕生,是基督教節日。

2. 圓頂鴿(圓頂街區)
   - 題目:你邀請信仰伊斯蘭教的同學來生日會,準備哪一種點心最合適?
   - 選項:A 豬肉香腸 B 水果拼盤 C 叉燒包
   - 答案:B
   - 解說:伊斯蘭教信徒不吃豬肉,香腸和叉燒包都有豬肉。

3. 星月貓(圓頂街區)
   - 題目:齋戒月期間,伊斯蘭教信徒什麼時候進食?
   - 選項:A 太陽下山以後 B 中午 C 整個月都不吃
   - 答案:A
   - 解說:齋戒是白天不吃不喝,日落後就可以進食。

4. 蓮花龜(蓮花河岸)
   - 題目:佛教起源於哪個地方?
   - 選項:A 印度 B 中國 C 日本
   - 答案:A
   - 解說:佛教由印度的釋迦牟尼創立,後來才傳到中國、日本。

5. 河岸牛(蓮花河岸)
   - 題目:招待一位信仰印度教的朋友吃飯,哪道菜最好避免?
   - 選項:A 牛肉麵 B 蔬菜咖哩 C 炒青菜
   - 答案:A
   - 解說:印度教視牛為神聖,許多信徒不吃牛肉。

6. 地球鸚鵡(中央廣場)
   - 題目:下列宗教和經典的配對,哪一個正確?
   - 選項:A 基督教—古蘭經 B 伊斯蘭教—古蘭經 C 佛教—聖經
   - 答案:B
   - 解說:古蘭經是伊斯蘭教經典,聖經是基督教經典。
