# 《節慶年曆大集合》
- 年級 / 科目 / 單元:國小三年級 / 社會 / 家鄉的節慶與習俗
- 學習目標:說出節慶的日期、習俗與先後順序。
- 遊戲概念:導覽員把習俗送到對的節慶,收集節慶。
- 回合規則:
  1. 抽1張習俗卡(手牌5張)。
  2. 放1張到對的節慶卡旁。
  3. 湊滿2張就收下得2分,依年曆翻下一個。
  4. 放錯被質疑:退回並少抽1張。
- 知識怎麼影響勝負:知道下一個節慶的人先留卡,一翻開就湊滿。
- 人數:單人對電腦 / 2~4 人

## 卡牌與題目
**節慶卡(8張,依年曆順序翻開,桌上一次放2張)**:春節(農曆1/1)、元宵節(農曆1/15)、清明節(國曆4月4或5日前後)、端午節(農曆5/5)、中元節(農曆7/15)、中秋節(農曆8/15)、重陽節(農曆9/9)、冬至(國曆12月21或22日前後)。
**習俗卡(每種2張,共32張)**:
- 春節:貼春聯、拿紅包
- 元宵節:提燈籠、猜燈謎
- 清明節:掃墓、吃潤餅
- 端午節:划龍舟、包粽子、掛艾草和菖蒲
- 中元節:普渡
- 中秋節:賞月、吃月餅、吃柚子
- 重陽節:敬老(重陽節也是敬老節)、登高
- 冬至:吃湯圓
(吃湯圓只算冬至;元宵節吃的是「元宵」,本遊戲不放這張避免爭議。)

1. 端午節是哪一天? A.農曆五月五日 B.國曆五月五日 C.農曆八月十五日 D.農曆一月十五日 → **A**。端午又叫「五月節」,是農曆。(B:把農曆當國曆)
2. 中秋節常吃什麼? A.粽子 B.月餅 C.湯圓 D.潤餅 → **B**。中秋賞月、吃月餅和柚子。
3. 清明節最重要的習俗是? A.划龍舟 B.猜燈謎 C.掃墓 D.貼春聯 → **C**。清明節祭拜祖先、掃墓。
4. 猜燈謎是哪個節日的活動? A.春節 B.元宵節 C.中元節 D.重陽節 → **B**。元宵節提燈籠、猜燈謎。
5. 重陽節在哪一天? A.農曆七月十五日 B.農曆九月九日 C.農曆一月一日 D.國曆九月九日 → **B**。兩個九相重,所以叫重陽。
6. 過年時家門口常貼什麼? A.艾草 B.春聯 C.燈籠謎題 D.月亮圖 → **B**。貼春聯是迎接新年的習俗。
7. 中元節的「普渡」是在做什麼? A.划船比賽 B.祭拜孤魂、分享食物 C.掃墓 D.賞月 → **B**。農曆七月舉行普渡。
8. 下面哪個節日最早出現在一年裡? A.中秋節 B.端午節 C.元宵節 D.重陽節 → **C**。元宵(1/15)→端午(5/5)→中秋(8/15)→重陽(9/9)。
