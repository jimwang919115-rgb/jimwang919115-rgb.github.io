# 《特徵收服大作戰》
- 年級 / 科目 / 單元:國小四年級 / 自然 / 動物的分類
- 學習目標:依特徵把動物分到五大類或無脊椎。
- 遊戲概念:觀察員派動物卡收服符合的特徵卡。
- 回合規則:
  1. 抽1張動物卡(手牌5張)。
  2. 把1張動物放到它符合的特徵卡上。
  3. 符合就收下得分;不符合就丟掉。
  4. 補翻1張特徵卡。
- 知識怎麼影響勝負:難的特徵分數高(如鯨魚配「用乳汁餵養幼兒」),懂分類才敢搶。
- 人數:單人對電腦 / 2~4 人

## 卡牌與題目
**動物卡(每種2張,共40張)**
- 魚類:吳郭魚、海馬、鯊魚
- 兩生類:青蛙、山椒魚
- 爬蟲類:烏龜、蛇、壁虎
- 鳥類:麻雀、企鵝、鴕鳥
- 哺乳類:狗、蝙蝠、鯨魚、鴨嘴獸(會下蛋,但用乳汁餵幼兒)
- 無脊椎(昆蟲):蝴蝶、獨角仙;無脊椎(非昆蟲):蜘蛛、蝸牛、蚯蚓

**特徵卡(每種3張,共24張)**
| 特徵卡 | 分數 | 符合的動物 |
|---|---|---|
| 有脊椎骨 | 1 | 魚、兩生、爬蟲、鳥、哺乳類 |
| 沒有脊椎骨 | 1 | 蝴蝶、獨角仙、蜘蛛、蝸牛、蚯蚓 |
| 體溫維持恆定 | 1 | 鳥類、哺乳類 |
| 身上有羽毛 | 2 | 鳥類 |
| 用乳汁餵養幼兒 | 2 | 哺乳類 |
| 一生都用鰓呼吸 | 2 | 魚類 |
| 小時候用鰓、長大用肺和皮膚呼吸 | 3 | 兩生類 |
| 身體分頭胸腹、有6隻腳 | 3 | 昆蟲(蜘蛛8隻腳,不算) |

1. 鯨魚屬於哪一類? A.魚類 B.哺乳類 C.兩生類 D.爬蟲類 → **B**。鯨魚用肺呼吸、用乳汁餵養幼鯨。(A:住在水裡就以為是魚)
2. 蝙蝠屬於哪一類? A.鳥類 B.昆蟲 C.哺乳類 D.爬蟲類 → **C**。蝙蝠身上有毛、用乳汁餵幼兒。(A:會飛就以為是鳥)
3. 企鵝不會飛,牠屬於? A.鳥類 B.哺乳類 C.魚類 D.兩生類 → **A**。企鵝身上有羽毛,是鳥類。
4. 蜘蛛為什麼不是昆蟲? A.牠會結網 B.牠有8隻腳 C.牠很小 D.牠有脊椎骨 → **B**。昆蟲6隻腳、身體分頭胸腹;蜘蛛8隻腳、身體分兩部分。
5. 青蛙屬於? A.爬蟲類 B.魚類 C.兩生類 D.哺乳類 → **C**。蝌蚪用鰓呼吸,長大用肺和皮膚呼吸。
6. 海馬屬於? A.哺乳類 B.魚類 C.爬蟲類 D.無脊椎動物 → **B**。海馬用鰓呼吸、有鰭,是魚類。
7. 鴨嘴獸會下蛋,為什麼還算哺乳類? A.牠住在水邊 B.牠用乳汁餵養幼兒 C.牠有嘴巴 D.牠會游泳 → **B**。用乳汁餵養幼兒是哺乳類的特徵。
8. 下列哪一種動物沒有脊椎骨? A.蛇 B.麻雀 C.蚯蚓 D.壁虎 → **C**。蚯蚓是無脊椎動物;蛇、壁虎是爬蟲類,麻雀是鳥類。
