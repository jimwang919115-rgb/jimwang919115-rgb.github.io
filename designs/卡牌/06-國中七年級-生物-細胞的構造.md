# 《細胞工程師》
- 年級 / 科目 / 單元:國中七年級 / 生物 / 細胞的構造
- 學習目標:說出構造功能,分辨各細胞有哪些構造。
- 遊戲概念:工程師用構造卡組出任務細胞得分。
- 回合規則:
  1. 抽2張構造卡(上限7張)。
  2. 拿1張任務卡(最多同時2張)。
  3. 放構造卡進任務,湊齊就宣告。
  4. 缺或多一種就失敗、卡全丟;對了得分。
- 知識怎麼影響勝負:知道洋蔥表皮沒葉綠體、紅血球沒細胞核,才不浪費卡,還能搶便宜任務。
- 人數:單人對電腦 / 2~4 人

## 卡牌與題目
**構造卡(共48張)**:細胞膜×10、細胞質×10、細胞核×8、粒線體×8、細胞壁×4、大液胞×4、葉綠體×4
- 細胞膜:控制物質進出 / 細胞質:進行許多生理作用的場所 / 細胞核:含遺傳物質,控制細胞活動 / 粒線體:分解養分、產生能量 / 細胞壁:支持和保護植物細胞 / 大液胞:儲存水分和物質 / 葉綠體:進行光合作用

**任務卡(每種3張,共12張)**
| 任務 | 需要的構造(每種1張) | 分數 |
|---|---|---|
| 人類成熟紅血球 | 細胞膜、細胞質(沒有細胞核和粒線體) | 2 |
| 口腔皮膜細胞 | 細胞膜、細胞質、細胞核、粒線體 | 3 |
| 洋蔥表皮細胞 | 細胞壁、細胞膜、細胞質、細胞核、粒線體、大液胞(沒有葉綠體) | 5 |
| 葉肉細胞 | 洋蔥表皮細胞的6種+葉綠體 | 6 |

1. 細胞產生能量的構造是? A.細胞核 B.粒線體 C.葉綠體 D.細胞壁 → **B**。粒線體分解養分釋放能量。(C:以為葉綠體「產能」;它是行光合作用製造養分)
2. 進行光合作用的構造是? A.葉綠體 B.粒線體 C.液胞 D.細胞膜 → **A**。葉綠體利用光能製造養分。
3. 含有遺傳物質的構造是? A.細胞質 B.細胞膜 C.細胞核 D.細胞壁 → **C**。細胞核含遺傳物質,控制細胞活動。
4. 植物細胞有、動物細胞沒有的構造是? A.細胞膜 B.粒線體 C.細胞核 D.細胞壁 → **D**。動物細胞沒有細胞壁。
5. 洋蔥表皮細胞沒有哪個構造? A.細胞壁 B.葉綠體 C.細胞核 D.細胞膜 → **B**。洋蔥表皮照不到光,沒有葉綠體。(植物細胞不一定都有葉綠體)
6. 控制物質進出細胞的是? A.細胞壁 B.細胞膜 C.細胞核 D.液胞 → **B**。細胞膜有選擇性控制進出;細胞壁主要是支持保護。
7. 人類成熟紅血球沒有哪個構造? A.細胞膜 B.細胞質 C.細胞核 D.以上都有 → **C**。成熟紅血球沒有細胞核,空間用來裝血紅素。
8. 植物細胞中儲存水分、使細胞飽滿的是? A.大液胞 B.粒線體 C.細胞核 D.葉綠體 → **A**。成熟植物細胞的大液胞儲存水分和物質。
