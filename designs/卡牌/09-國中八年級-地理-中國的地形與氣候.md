# 《大地圖探險隊》
- 年級 / 科目 / 單元:國中八年級 / 地理 / 中國的地形與氣候
- 學習目標:說出主要地形區的氣候與生活景觀。
- 遊戲概念:探險隊長湊齊同地區的卡,占領地區。
- 回合規則:
  1. 抽1張或撿棄牌堆頂1張(上限7張)。
  2. 打出同地區組合:地形+景觀2分,再加氣候5分。
  3. 組錯被質疑:收回卡,質疑者得1分。
  4. 丟1張到棄牌堆。
- 知識怎麼影響勝負:氣候卡多區共用,懂的人湊得靈活,丟牌也不送對手要的卡。
- 人數:單人對電腦 / 2~4 人

## 卡牌與題目
**地形卡(每種2張,共18張)、景觀卡(每種2張,共18張)**
| 地形區 | 氣候 | 景觀卡 |
|---|---|---|
| 青藏高原 | 高地氣候 | 犛牛放牧 |
| 內蒙古高原 | 乾燥氣候 | 蒙古包與游牧 |
| 塔里木盆地 | 乾燥氣候 | 沙漠綠洲與坎兒井 |
| 黃土高原 | 溫帶季風氣候 | 窯洞 |
| 東北平原 | 溫帶季風氣候 | 黑土與大豆 |
| 華北平原 | 溫帶季風氣候 | 小麥旱作 |
| 長江中下游平原 | 副熱帶季風氣候 | 稻米、魚米之鄉 |
| 四川盆地 | 副熱帶季風氣候 | 天府之國 |
| 雲貴高原 | 副熱帶季風氣候 | 石灰岩(喀斯特)地形 |

**氣候卡(共14張)**:高地氣候×2、乾燥氣候×3、溫帶季風氣候×4、副熱帶季風氣候×5(與地形區數成比例)。

1. 中國地勢大致是? A.東高西低 B.西高東低 C.南高北低 D.中間高四周低 → **B**。西部高原、東部平原,河流多向東流。(A:搞混方向)
2. 青藏高原屬於哪種氣候? A.熱帶季風 B.溫帶季風 C.高地氣候 D.副熱帶季風 → **C**。海拔高,氣溫低,屬高地氣候。
3. 窯洞是哪個地形區的代表民居? A.黃土高原 B.四川盆地 C.長江中下游平原 D.雲貴高原 → **A**。黃土厚實、能挖洞,冬暖夏涼。
4. 被稱為「天府之國」的是? A.華北平原 B.四川盆地 C.塔里木盆地 D.東北平原 → **B**。四川盆地土壤肥沃、物產豐富。
5. 塔里木盆地氣候乾燥,主要因為? A.緯度太低 B.距海遠,季風難到 C.海拔太高 D.靠近赤道 → **B**。深居內陸,海洋水氣難以到達。
6. 中國溫帶季風氣候與副熱帶季風氣候的分界大約是? A.長江 B.黃河 C.秦嶺-淮河 D.萬里長城 → **C**。秦嶺-淮河線大致是一月均溫0°C、年雨量800毫米的界線。(A:以為長江是南北界)
7. 長江中下游平原主要糧食作物是? A.小麥 B.稻米 C.青稞 D.玉米 → **B**。夏季高溫多雨,適合種稻,被稱為魚米之鄉。
8. 雲貴高原常見的特殊地形是? A.冰河地形 B.石灰岩(喀斯特)地形 C.沙丘 D.三角洲 → **B**。石灰岩受水溶蝕,形成石林、溶洞。
