# 《湊數小站長》
- 年級 / 科目 / 單元:國小二年級 / 數學 / 二位數的加減
- 學習目標:會算含進退位的二位數加減。
- 遊戲概念:站長用數字卡湊出目標站號,搶車票。
- 回合規則:
  1. 翻1張目標卡。
  2. 抽1張數字卡(手牌5張)。
  3. 選2張數字卡相加或相減。
  4. 等於目標得3票,差1~5得1票。
- 知識怎麼影響勝負:會進退位心算的人比得出更多組合;算錯就沒分。
- 人數:單人對電腦 / 2~4 人

## 卡牌與題目
**數字卡(40張)**:10~49 每個數 1 張。
**符號卡(每人各1張「+」、1張「−」,可重複使用)**:減法時大數放前面。
**目標卡(20張)**:50、55、60、63、68、70、72、75、80、81、84、86、88、90、91、93、95、97、98、99(結果須在 0~99)。
例:目標 72,手牌 38、25、47、19 → 47+25=72(剛好,3張);38+25=63(差9,不得分)。

1. 38+25=? A.53 B.63 C.513 D.73 → **B**。8+5=13,進1到十位:3+2+1=6。
2. 72−36=? A.44 B.36 C.46 D.34 → **B**。2不夠減6,向十位借1:12−6=6,6−3=3。(A 是把 6−2 倒過來減)
3. 45+47=? A.82 B.92 C.812 D.93 → **B**。5+7=12,進1:4+4+1=9。
4. 90−27=? A.70 B.73 C.63 D.67 → **C**。0不夠減7,借1:10−7=3,8−2=6。
5. 哪一組等於 60? A.45+25 B.81−11 C.26+34 D.73−23 → **C**。26+34=60;A、B 是 70,D 是 50。
6. 56−29=? A.33 B.27 C.37 D.23 → **B**。16−9=7,4−2=2。
7. 小明有 48 張貼紙,又拿到 36 張,共幾張? A.74 B.84 C.712 D.86 → **B**。8+6=14,進1:4+3+1=8。
8. 64−□=28,□是多少? A.36 B.46 C.44 D.92 → **A**。64−28=36,驗算 28+36=64。
