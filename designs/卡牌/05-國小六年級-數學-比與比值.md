# 《比值大樓占領戰》
- 年級 / 科目 / 單元:國小六年級 / 數學 / 比與比值
- 學習目標:會算比值、判斷相等的比並解題。
- 遊戲概念:建築師把比卡蓋到比值相同的大樓,蓋滿占領。
- 回合規則:
  1. 抽1張比卡(手牌5張)。
  2. 放到比值相同的大樓,得1分(小數、分數卡2分)。
  3. 放錯被質疑:卡丟掉,質疑者得1分。
  4. 放第4張的人占領,再得3分。
- 知識怎麼影響勝負:會算比值才看得出0.5:1就是1:2;懂的人留卡到第4張。
- 人數:單人對電腦 / 2~4 人

## 卡牌與題目
**大樓卡(4棟,比值寫在樓頂)**:1/2、2/3、3/4、3/2(每棟占領後換一張同比值的新大樓,共用同一副比卡)

**比卡(共32張,每種2張)**
| 大樓比值 | 比卡 |
|---|---|
| 1/2 | 1:2、3:6、5:10、0.5:1(2分) |
| 2/3 | 2:3、4:6、10:15、0.4:0.6(2分) |
| 3/4 | 3:4、6:8、9:12、1.5:2(2分) |
| 3/2 | 3:2、6:4、9:6、1/2:1/3(2分) |
陷阱:2:3 和 3:2 前後項相反,比值不同。驗算:0.4÷0.6=2/3;1.5÷2=3/4;(1/2)÷(1/3)=3/2。

1. 6:8 的比值是? A.4/3 B.3/4 C.2 D.6/14 → **B**。6÷8=3/4。(A:後項除以前項)
2. 12:18 化成最簡整數比是? A.2:3 B.3:2 C.4:6 D.6:9 → **A**。同除以6得2:3;C、D還能再約。
3. 哪一個和 4:5 相等? A.5:4 B.8:9 C.12:15 D.14:15 → **C**。4×3=12、5×3=15。(B:前後各加4,比值會變)
4. 0.6:0.9 的最簡整數比是? A.6:9 B.2:3 C.3:2 D.1:3 → **B**。同乘10得6:9,再同除以3得2:3。
5. 1/2:1/3 的最簡整數比是? A.2:3 B.1:3 C.3:2 D.1:2 → **C**。同乘6得3:2。
6. 果汁和水的比是 2:3,用了 8 杯果汁,要加幾杯水? A.9 B.12 C.11 D.3 → **B**。2×4=8,所以 3×4=12。(C:以為多1杯就是加1,8+3=11)
7. 5:2 的比值是? A.2/5 B.2.5 C.0.4 D.3 → **B**。5÷2=2.5。
8. 班上男女生人數比 3:4,全班 28 人,男生幾人? A.12 B.16 C.21 D.7 → **A**。3+4=7,28÷7=4,男生 3×4=12。
