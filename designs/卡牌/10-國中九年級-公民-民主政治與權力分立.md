# 《五院守護戰》
- 年級 / 科目 / 單元:國中九年級 / 公民 / 民主政治與權力分立
- 學習目標:判斷各機關職權,說明分權制衡的用意。
- 遊戲概念:憲政守護者派職權卡處理國家事件。
- 回合規則:
  1. 抽1張職權卡(手牌5張)。
  2. 對桌上事件打出能處理它的職權卡。
  3. 對了收下事件得分;錯了卡丟掉。
  4. 補翻1張事件卡。
- 知識怎麼影響勝負:事件只寫情境,要懂誰編預算、誰審、誰判違憲才選得對;制衡事件分數最高。
- 人數:單人對電腦 / 2~4 人

## 卡牌與題目
**職權卡(每種3張,共33張)**
| 職權卡 | 機關 |
|---|---|
| 編列預算、執行政策 | 行政院 |
| 三讀通過法律 | 立法院 |
| 審議預算 | 立法院 |
| 質詢行政院長與部會首長 | 立法院 |
| 審判案件 | 司法院(各級法院) |
| 宣告法律違憲 | 司法院(憲法法庭) |
| 舉辦國家考試 | 考試院 |
| 彈劾、糾舉違法失職公務員 | 監察院 |
| 審計政府花錢是否合法 | 監察院 |
| 任命行政院長 | 總統 |
| 公布法律 | 總統 |

**事件卡(共16張)**
- 1分(單一機關做事):明年要蓋新捷運,先編經費 →編列預算;某人被控偷竊,要判決 →審判案件;要招考新公務員 →舉辦國家考試;新法要成為法律 →三讀通過法律;法律通過後要正式生效 →公布法律;新內閣要上任 →任命行政院長。(各2張)
- 3分(制衡):政府預算太浮濫 →審議預算;市長被指違法失職 →彈劾、糾舉;某條法律被認為侵害人權 →宣告法律違憲;議員想了解政策成效 →質詢。(各1張)

1. 權力分立最主要的目的是? A.讓政府效率最高 B.防止權力集中而濫權,保障人權 C.讓總統權力最大 D.減少選舉 → **B**。權力分開、互相制衡,避免獨裁。(A:以為分權是為了效率)
2. 提出三權分立學說的是? A.孟德斯鳩 B.孔子 C.孫中山 D.亞里斯多德 → **A**。孟德斯鳩主張立法、行政、司法三權分立。
3. 審議中央政府預算的機關是? A.行政院 B.立法院 C.監察院 D.考試院 → **B**。行政院編列,立法院審議。(A:編列和審議搞混)
4. 舉辦公務人員考試的機關是? A.行政院 B.考試院 C.教育部 D.司法院 → **B**。考試院掌理國家考試。
5. 公務員違法失職,可由哪個機關彈劾? A.立法院 B.監察院 C.行政院 D.總統府 → **B**。監察院有彈劾、糾舉、糾正、審計權。
6. 判斷法律是否違憲的是? A.立法院 B.行政院 C.司法院大法官組成的憲法法庭 D.總統 → **C**。憲法法庭審理法律違憲案件。
7. 行政院長如何產生? A.人民直選 B.由總統任命 C.立法院選出 D.考試錄取 → **B**。現行憲法增修條文規定由總統任命,不需立法院同意。
8. 民主政治中,政府施政要依照法律,稱為? A.法治原則 B.多數決 C.責任政治 D.人民主權 → **A**。法治是政府和人民都要守法、依法行政。
